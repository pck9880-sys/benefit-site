# [이어서 작업] 정보 전달형 3D 숏츠 만들기 (Mac 로컬)

너는 내 유튜브 숏츠 채널 '해요잉'(@HAEYOING) 제작을 돕는다. 답은 한국어, 휴대폰으로 보기 좋게 짧은 요약·표로.
저장소: ~/benefit-site (git). 먼저 `git pull` 하고 `.claude/skills/shorts/SKILL.md` 전체를 읽어라.
특히 '정보 전달형 템플릿', '공중제비 장면(make_flip)', '자막(box) 한 문장 = 한 자막' 규칙을 따른다.

## 목표
참고 스타일: 지도·지구 위로 3D 비행기가 날고, 점선 항로·화살표·숫자 라벨이 애니메이션되는 과학 설명 숏츠.
(남의 영상은 내려받거나 베끼지 않는다. 구성·연출만 참고해서 우리 것으로 새로 만든다.)

## 할 일
1. **3D 애니메이션 엔진** 만들기 — Blender(무료, `brew install --cask blender`) + Python(bpy) 스크립트로 렌더:
   - `bot/scene3d.py` (또는 `scripts/blender/`): 장면 설정(JSON) → Blender 백그라운드 렌더(`blender -b -P ...`) → 1080x1080, 30fps, 3~6초 mp4.
   - 기본 장면 3종: ① 지구본 위 두 도시 사이 **대권항로(곡선) 따라 비행기 이동** + 점선 궤적이 그려짐
     ② 평면 지도(메르카토르) 위 직선 vs 곡선 비교 + 거리/시간 숫자 라벨 ③ 카메라가 천천히 도는 3D 오브젝트 클로즈업.
   - 지구 텍스처는 퍼블릭 도메인만 (예: NASA Blue Marble). 비행기 모델은 단순 도형으로 직접 만들거나 CC0 모델만. 출처를 plan.json credits 에 기록.
   - 렌더 결과는 기존 파이프라인의 media `{"video": "clipN.mp4"}` 로 바로 쓰이게 assets/samples/<slug>/ 에 저장.
   - Blender 렌더가 너무 느리면 Eevee, 낮은 샘플 수, 720p 렌더 후 업스케일.
2. **첫 영상**: 주제 "비행기는 왜 휘어서 날까? (대권항로)" — 인천→뉴욕 예시.
   - 사실 확인: 공식·신뢰 자료(항공사, 국토부, 백과, 교과서 수준 자료)로 확인한 숫자·용어만. 확인 못 한 숫자는 쓰지 않는다.
   - 대본 9~11문장, 존댓말 설명체: 문제(답답함) → "**~때문에 미쳐서 공중제비를 돌아버립니다**"(딱 1번, 이 장면은 make_flip 공중제비 화면, 주인공 = いらすとや 파일럿 짤)
     → 해결(전문 용어 '대권항로' 쉬운 말 풀이) → 원리 → 결론 "**~해서 ~덕분에 ~된 겁니다**".
   - plan.json: caption_style "box", outro_custom true + outro = 결론 문장, 제목 2줄(핵심 단어 강조), yt_title, description(출처 포함), pin_comment, tags, sources, credits.
   - 화면: 3D 장면 3~4개 + 공중제비 1개 + 필요하면 AI 이미지 1~2개(Figma generate_image, 얼굴·글자·로고 없음).
   - 렌더: `python3 -c "from bot import shorts; shorts.render_sample('assets/samples/<slug>')"` (임시 음성) → 미리보기 확인.
3. 나에게 줄 것: 미리보기 mp4 경로, **용식 녹음 대본**(1.0배속, 코드블록), 제목·설명·고정 댓글. 업로드·텔레그램 전송은 하지 않는다.
4. 잘 되면 SKILL.md 의 정보형 템플릿에 '3D 장면 만드는 법'을 추가하고, 지정한 경로만 git add 해서 커밋 (`git commit -a` 금지).
