[종류 규칙: 유머]
- 커뮤니티(더쿠·네이트판·인스티즈·에펨코리아·블라인드 등) 공개 웃긴 글 2~3개를 WebSearch/WebFetch 로 찾아
  실제 상황들을 짜깁기해 하나의 썰로 새로 쓴다(원문 통째 복사 금지, 개인 신상 제거). 반전·황당 포인트가 분명한 것.
- 짤: **페페(Pepe the Frog) 짤 2~3장**. 보관함 ~/쇼츠작업/짤/페페/ 에서 상황에 맞는 것 → 폴더에 z1.png, z2.png … 로 복사.
  부족하면 WebSearch 로 찾아 `curl -sfL -o ~/쇼츠작업/짤/페페/<영어설명>.png <URL>` 로 보관함에 추가(가능하면 256px 이상).
  혐오·정치 상징 페페 변형 금지.
- 실제 사진 0~2장(선택).
