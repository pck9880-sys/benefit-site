[숏츠 자동 제작 – 1회 1편 / Mac 로컬용. 제작만 하고, 더빙·업로드는 다음 단계 스크립트가 자동으로 함]

0) 종류: 맨 아래 [이번 회차] 줄에 적힌 종류로 만든다 (순서: 유머 2 → 감동 1 → 핫이슈 2 → 다시 유머, 스크립트가 지정).
   plan.json 에 "mood" 기록: 유머 = "웃긴글", 감동 = "감동", 핫이슈 = "mood": "기본" + "kind": "이슈".
   주제는 assets/samples/*/plan.json 의 topic, _queue.md 와 겹치지 않게.
   공통 제외: 정치·선거·사망·사고·범죄피해·연예인 사생활·특정 개인 비방. 스포츠는 축구만.

1) 종류별 규칙
   ■ 기본(일상 썰) — 커뮤니티 실제 썰 재구성
     - WebSearch/WebFetch 로 커뮤니티(더쿠·네이트판·인스티즈·에펨코리아·블라인드 등) 공개 글 2~3개를 찾아
       실제 썰의 상황들을 짜깁기해 하나의 이야기로 다시 쓴다. 문장은 직접 새로 쓴다(원문 통째 복사 금지).
       개인 신상(실명·회사·학교·지역 특정)은 빼거나 바꾼다.
     - 커뮤니티 댓글·반응 카드 2~3개: 원글에 **실제로 달린** 댓글만(지어내기 금지), overlay "comment", source "커뮤니티 반응".
       닉네임은 쓰지 않는다. 베스트 댓글 위주.
     - 설명란 끝에 "※ 커뮤니티 실제 사연 여러 개를 재구성했어요." 와 출처 사이트명.
     - 짤: いらすとや 1~2장 가능 (`python -m bot.irasutoya <일본어>` → bot.irasutoya.save).
   ■ 웃긴글 — 짤은 **페페(Pepe the Frog) 짤** 2~3장
     - 짤 보관함 ~/쇼츠작업/짤/페페/ 에서 상황에 맞는 것 고르기. 부족하면 WebSearch 로 페페 밈 이미지를 찾아
       `curl -sfL -o ~/쇼츠작업/짤/페페/<영어설명>.png <URL>` 로 보관함에 추가 후 사용 → 폴더에 zN.png 로 복사, media 에 {"zzal": "zN.png"}.
     - 혐오·정치 상징으로 쓰이는 페페 변형(나치·인종 관련 등)은 절대 쓰지 않는다.
     - 웃긴 썰도 커뮤니티 실제 글 기반('기본' 규칙처럼 재구성 + 실제 댓글 카드).
   ■ 감동 — **짤 사용 자제(0장)**. AI 이미지만, 잔잔하고 따뜻한 연출.
     실제 사연(기사·커뮤니티)을 바탕으로 쓰고, 지어낸 이야기를 실화처럼 쓰지 않는다.
   ■ 이슈(뉴스) — shorts 스킬의 '한국 뉴스형' 그대로. WebSearch 로 2곳 이상 언론 확인, 기사 제목 카드(headline) 2~3개.

2) 공통 제작
   - 첫 장면은 자동으로 '커뮤니티 글 첫 화면' 카드(흰 바탕 + 이모지·게시판 이름 + 글 제목). 제목을 따로 정하려면
     plan.json "intro_post": {"title": "첫 줄\n둘째 줄"} (줄당 10자 안팎, 어절 단위로 나눔). 첫 beat 는 이 카드 위에서 읽히는 훅 문장.
   - 자막: **caption_style "mix"** (흰+검정테두리 / 빨강+흰테두리 / 검정+흰테두리 둥근글씨 / 주황빨강+검정테두리 4종을 장면마다 섞음). 모든 종류 공통.
   - 대본 11~12문장(반말 썰 말투, 한 문장 30자 이내, 훅→상황→전개→반전→마무리). question 은 비움. 마무리는 자동('님들은 어떻게 생각해요잉?').
   - AI 이미지 4장: **직접 만들지 않는다 (Figma 사용 안 함).** plan.json 에 "gpt_images": [{"file": "img0.jpg", "prompt": "<영어 프롬프트>"}, ...] 로 적기만 하면
     다음 단계 스크립트가 ChatGPT 로 생성한다. media 에는 그 파일 이름을 그대로 쓴다. 사람은 가상 인물만, 글자·로고 없음, 장면마다 구체적으로.
   - **실제 사진 섞기**: AI 이미지와 함께 실제 사진 1~3장(기사 대표 이미지 og:image, 커뮤니티 글 사진, 제품 공식 사진 등).
     `python -m bot.realimg <URL> assets/samples/<slug>/rN.jpg <모드>` → media 에 {"image": "rN.jpg"}.
     모드: 제품·음식·풍경(사람 없음) = none 그대로 / 사람 나오면 auto(얼굴·머리 모자이크) / 집회·군중 = all(전체 흐림).
     사람이 조금이라도 보이면 none 금지. 결과 줄의 '(얼굴 N개…)' 를 보고 얼굴이 남았으면 all 로 다시.
     워터마크·방송 로고가 크게 박힌 사진, 커뮤니티 사진 중 개인 신상이 드러나는 것(카톡 프로필·이름표 등)은 쓰지 않는다.
     설명란에 "※ 일부 실제 사진은 모자이크 처리했어요." 한 줄.
   - **배경음악은 넣지 않는다** (업로드 때 스튜디오 오디오 보관함에서 고름). plan.json 에 "music_concept": "잔잔한 감동" | "신나는 코믹" | "일상 브이로그" | "긴장감 이슈".
   - 썸네일(기본값): 웃긴글·기본이면 `python -m bot.thumb prompt assets/samples/<slug>` 문구 그대로 gpt_images 에 {"file": "thumb_src.jpg", "prompt": ...} 로 추가.
     문구의 조건(성인·옷 다 입음·V넥 가슴골 살짝 허용·속옷/수영복/노출/선정적 자세 금지)은 빼거나 바꾸지 않는다.
     plan.json 에 "thumb_caption": 이미지 아래 자막 상자에 넣을 훅 한 마디(15자 이내). 감동이면 생략(장면 컷).
   - 끝 장면은 자동으로 '댓글·반응 캡처' 카드. plan.json "end_comments": [{"text": "...", "likes": 숫자}, ...] 에 원글의 **실제 댓글** 3~5개
     (베스트 댓글 위주, 공감수 있으면 함께, 닉네임 제외, 지어내기 금지). 이슈는 기사에 인용된 실제 반응·커뮤니티 실제 댓글.
   - 더빙은 1.2배속 고정. 대본 13문장 기준 30초 안팎.
   - **렌더·썸네일 합성은 하지 않는다** (이미지 생성 뒤 다음 단계 스크립트가 함).
   - plan.json 에 yt_title(#shorts), description, tags, sources, pin_comment 포함.
