[숏츠 자동 제작 – 1회 1편 / Mac 로컬용. 대본·자료만 만들고, 이미지·더빙·합성·업로드는 다음 단계 스크립트가 자동으로 함]
사용자에게 묻거나 보고하지 않는다. 결과 보고는 3줄 이내.

0) 종류와 템플릿: 맨 아래 [이번 회차] 종류로 만든다. **과학이면 아래 [종류 규칙: 과학]이 공통 규칙보다 우선**(장면 순서·음슴체·짤 규칙 대신 과학 규칙). 먼저 뼈대 만들기:
   `python -m bot.plan_tool new <영문슬러그> <웃긴글|감동|이슈|과학>` → assets/samples/<slug>/plan.json 의 빈칸만 채운다.
   주제는 assets/samples/*/plan.json 의 topic, _queue.md 와 겹치지 않게.
   공통 제외: 정치·선거·사망·사고·범죄피해·연예인 사생활·특정 개인 비방. 스포츠는 축구만.

1) 채울 것 (종류별 규칙은 아래 [종류 규칙])
   - topic, title_top/title_bottom: **각 줄 공백 빼고 9자 이내**, 짧고 임팩트 (예: "가격이 싸졌는데" / "살 수가 없음").
   - beats[].narration **8~10개 (영상 28초 미만)**: 음슴체 바탕이되 **자연스럽게 이어지는 썰 말투**. 같은 끝맺음을 연달아 쓰지 않는다.
     끝맺음을 섞는다: "~함/~했음/~임/~됨" + 이어 주는 말 "~했는데/~하더니/~해서/~니까" + 명사로 끝("결과는 두 봉투.") + "~라고 함" + "ㅋㅋ".
     문장끼리 '근데/그래서/결국/알고 보니' 로 이어서 한 편의 이야기처럼. 예:
       "엄마한테 김치 두 포기만 달라고 했는데" → "주말에 들고 온 게 김장봉투 두 개" → "이게 두 포기라고 함ㅋㅋ"
     "~요/~습니다/해요잉" 금지. 한 문장 30자 이내. 마무리 멘트('님들 생각은 어떰?')는 자동이라 쓰지 않는다. 남는 빈 beat 는 지운다.
   - **장면 순서 고정**: 썸네일 → AI 이미지 → 일본짤 → 일본짤 → 페페 → AI 이미지 → 일본짤 (문장 수만큼 반복) → 끝 장면 댓글 캡처.
     **실제 글자가 적힌 이미지(커뮤니티 캡처·기사 화면·글자 카드)는 쓰지 않는다.** 필요 수(문장 10개 기준): AI 4장, 일본짤 i1~i5.png 5장, 페페 z1~z2.png 2장.
     · 일본짤: `python -m bot.irasutoya <일본어 검색어>` → `python -c "from bot import irasutoya; irasutoya.save('<URL>', 'assets/samples/<slug>/i1.png')"` (i1.png, i2.png …)
       문장 상황에 맞는 것 (예: 驚く, 怒る母, キムチ, 冷蔵庫). 한 작품 20장 이하 규약. 장면마다 다른 그림으로.
     · 페페짤: ~/쇼츠작업/짤/페페/ 에 있는 것만 (사용자가 직접 준 검증된 짤). 파일 이름이 감정. **새로 검색해서 받지 않는다**(엉뚱한 사진이 받아진 적 있음). 같은 편에 같은 짤 반복 가능 → z1.png, z2.png
     · AI 이미지는 **진짜 사진처럼** (스마트폰 실사 느낌, 과장된 상황). 짤과 번갈아 배치(도구가 자동).
   - **화면 전환은 적게**: 같은 사진·장면이 2문장 이어지는 구간을 2~3번 둔다(media 에 같은 파일 연속). 확대 효과는 약하게(자동).
   - **짤은 중간중간 필수**: 3~4문장마다 일본짤 또는 페페짤이 한 번은 나오게.
   - **끝 반응은 디시 갤러리 느낌**(자동 카드): end_comments 는 실제 반응만(커뮤니티 댓글·갤러리 글 제목), 닉네임·IP 는 자동으로 가림,
     추천 수는 실제 값이 있을 때만. end_label 에 갤러리·게시판 이름(예: "해외축구 갤러리").
   - gpt_images[].prompt: 장면별 영어 프롬프트 (구체적으로, 사람은 가상 인물). 스타일 꼬리·썸네일 문구는 도구가 자동으로 붙인다.
   - 대본 길이: 공백 빼고 **130자 이내** (영상 28초 미만). 문장은 짧게(15자 안팎).
   - thumb_caption (15자 이내 훅, 감동은 비워도 됨), end_comments: 원글 **실제 댓글** 3~5개 [{"text","likes"}] (닉네임 제외, 지어내기 금지).
   - yt_title(20자 안팎, #shorts 자동), description(음슴체, 고지문은 도구가 자동), pin_comment(음슴체 질문), sources(출처 URL).
   - **실사 사진은 넣지 않는다** (2026-11-20). 실제 물건·상황도 AI 이미지로 — 누가 봐도 진짜 사진 같은 극사실 스타일로, 상황은 과장되게.
2) `python -m bot.plan_tool check <slug>` → '고칠 것' 이 나오면 고치고 다시. OK 가 나오면 끝(장면 배치·썸네일·고지문은 자동).
   렌더·썸네일 합성·이미지 생성은 하지 않는다.
3) assets/samples/_queue.md 맨 아래에: 순서번호 · 만든 시각 · 종류 · slug · 제목 · 핵심 한 줄 · 녹음 대본(코드블록).
4) git add 로 그 폴더와 _queue.md 만 지정해서 커밋 (git commit -a 금지). push 는 가능하면.
5) 실패하면 _queue.md 에 '실패: 이유' 한 줄만 남기고 끝낸다.
