[숏츠 더빙 – 크롬 Claude 자동 입력 / 결제·업그레이드 금지 / 사용자에게 묻지 않음 / 결과 보고 3줄 이내]

작업 폴더: {{DIR}}  (로컬 서버 http://127.0.0.1:{{PORT}}/ 가 이 폴더를 연결)
한 숏츠에 목소리 2명: 본문은 '{{MAIN_VOICE}}', 마지막 멘트만 '{{OUTRO_VOICE}}'. (캐릭터는 자바바·제롬·구리 셋만 사용, 다른 캐릭터 금지)
  - 본문 대본: {{DIR}}/더빙용/대본_본문.txt (한 줄 = 한 문장) → 캐릭터 '{{MAIN_VOICE}}' → 저장 이름 더빙용/voice_main.mp3
  - 마무리 대본: {{DIR}}/더빙용/대본_마무리.txt (한 줄) → 캐릭터 '{{OUTRO_VOICE}}' → 저장 이름 더빙용/voice_outro.mp3

1) 크롬에서 타입캐스트(typecast.ai) 편집기를 연다. 로그인돼 있지 않으면 '실패: 타입캐스트 로그인 필요' 를 {{DIR}}/결과.txt 에 쓰고 끝.
2) 새 프로젝트 하나에서 해도 되고 둘로 나눠도 된다. 캐릭터는 찜 목록에서, 없으면 캐릭터 검색으로 정확한 이름을 찾는다.
   대본을 한 줄에 한 문장씩 그대로 입력. 속도·톤 등 전부 기본값(1.0).
3) 본문·마무리를 **각각 따로** mp3 로 받는다(본문은 '전체 합치기' 한 파일). **저장 창이 뜨지 않게** 다운로드 동작을 막고 오디오 주소(cdn.typecast.ai/...)만 얻는다.
   타입캐스트 페이지에서 127.0.0.1 로 바로 보내면 크롬이 막는다 → 수신 페이지를 거친다:
   `const w = window.open('http://127.0.0.1:{{PORT}}/_recv.html')` (팝업이 막히면 페이지에 임시 버튼을 넣어 클릭으로 연다)
   → ready 메시지 후 `const b = await (await fetch(오디오주소)).blob(); w.postMessage({file:'더빙용/voice_main.mp3', blob:b}, '*')`
   → ack status 201 이면 성공. 마무리도 같은 방법으로 '더빙용/voice_outro.mp3'.
   Bash 로 `ls -l {{DIR}}/더빙용/voice_main.mp3 {{DIR}}/더빙용/voice_outro.mp3` 확인(본문 100KB, 마무리 10KB 이상). 팝업은 닫는다.
4) 쓴 캐릭터를 {{DIR}}/voice_used.txt 에 "본문:<이름> 마무리:<이름>" 한 줄로.
5) 업그레이드·결제 창이 뜨면 닫고 '실패: 요금제 한도' 를 결과.txt 에 쓰고 끝.
6) 확인창(confirm/alert)을 띄우는 동작 금지. 연 탭은 끝나면 닫는다.
