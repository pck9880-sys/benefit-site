[숏츠 더빙 – 크롬 Claude 자동 입력 / 결제·업그레이드 금지]

작업 폴더: {{DIR}}  (로컬 서버 http://127.0.0.1:{{PORT}}/ 가 이 폴더를 연결)
대본: {{DIR}}/더빙용/대본.txt (한 줄 = 한 문장)

1) 크롬에서 타입캐스트(typecast.ai) 편집기를 연다. 로그인돼 있지 않으면 '실패: 타입캐스트 로그인 필요' 를 {{DIR}}/결과.txt 에 쓰고 끝.
2) 새 프로젝트, 캐릭터 '{{VOICE}}'. 대본을 한 줄에 한 문장씩 그대로 입력. 속도·톤 등 전부 기본값(1.0).
3) 전체 합치기 mp3 로 받는다. **다운로드 버튼을 누르면 저장 창이 떠서 멈춘다 → 누르지 말 것.**
   대신 다운로드 링크(또는 생성 API 응답의 오디오 URL)를 찾아 페이지 안에서:
   `const b = await (await fetch(URL)).blob(); await fetch('http://127.0.0.1:{{PORT}}/더빙용/voice.mp3', {method:'PUT', body:b});`
   응답이 201 이면 성공. Bash 로 `ls -l {{DIR}}/더빙용/voice.mp3` 확인(100KB 이상).
4) 업그레이드·결제 창이 뜨면 닫고 '실패: 요금제 한도' 를 결과.txt 에 쓰고 끝.
5) 확인창(confirm/alert)을 띄우는 동작 금지. 연 탭은 끝나면 닫는다.
