# Benefy (정부혜택을 한눈에) 로드맵

## 다음 할 일 (순서대로)
1. **도메인 연결** — 사용자가 도메인 구매(예: benefy.kr) → Cloudflare Pages 사용자 도메인 추가 → SITE_URL 변경 → 옛 주소 리디렉션 → 서치콘솔·서치어드바이저 새 주소 등록
2. **콘텐츠 확장**
   - 계산기: 실업급여, 육아휴직급여, 근로장려금 예상액 (공식 계산식 확인 후)
   - 질문형 글 자동 생성: "A랑 B 같이 받을 수 있나요?"
   - 지역별 지원금 페이지 (17개 시·도, 지자체 데이터 수집 확대)
   - 월별 신청 캘린더 자동 갱신, 계산 결과 공유 카드
3. **수익 장치**: 쿠팡 파트너스(혜택 관련 절약템 박스, 대가성 문구 필수) → 글 50개+ 후 애드센스 신청(글 35개 넘으면 텔레그램 알림 설정됨)
4. **알림**
   - 카카오톡 채널(사용자가 개설) + 봇이 매주 월요일 '이번 주 새 지원금' 문안·카드 생성 → 수동 발송, 사이트에 채널 추가 버튼
   - 웹 푸시(무료 서비스, 서버 불필요), 이메일 뉴스레터(무료 플랜)
5. **로그인 없는 개인화**: 찜하기(브라우저 저장), 조건 검색 조건 기억

## 나중에 (보류)
- **네이버·카카오 간편 로그인**: Cloudflare Pages Functions + D1로 서버 없이 가능.
  보류 이유: 개인정보 관리 책임, 카카오 비즈앱(사업자등록) 필요, 네이버 검수, 정보 사이트 특성상 이용률 낮음.
  재검토 시점: 하루 방문자 수백 명 이상 + 알림·찜 이용자 증가, 또는 사업자등록 후 알림톡과 함께.
- **카카오 알림톡 자동 발송**: 사업자등록 + 발송대행사 + 템플릿 심사 필요.
- **다크 모드 자동 전환(☀️/🌙)**: 현재는 홈 상단만 다크인 절충안 유지.
