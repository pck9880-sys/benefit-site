Benefy(베네피) 소개

Benefy(베네피)는 정부·지자체 지원금과 혜택을 금액 중심으로 쉽게 정리하는 민간 안내 사이트예요. 주소는 benefy.kr이에요.

{{ site_name }}은(는) 복잡한 정부 지원제도를 누구나 쉽게 이해할 수 있도록 정리하는 정보 사이트입니다.

모든 글은 행정안전부가 공개하는 「대한민국 공공서비스(혜택) 정보」 공공데이터를 바탕으로 작성되며, AI의 도움을 받아 읽기 쉽게 정리한 뒤 게시됩니다. 각 글 하단에는 정부24 공식 안내 링크를 함께 제공합니다.

누가 운영하나요

베네피는 운영자 1명이 만들고 관리하는 개인 프로젝트예요. 사이트 디자인, 계산기·진단 같은 도구 기획, 운영 가이드 글은 운영자가 직접 만들고, 지원제도 안내글은 아래 과정을 거쳐 자동으로 작성·검수돼요. 정부·공공기관과는 관계가 없는 민간 사이트예요.

궁금한 점이나 틀린 내용은 문의로 알려주세요. 운영자가 직접 읽고 답해요.

이렇게 만들어요

  1. 공공데이터 수집 · 행정안전부 「대한민국 공공서비스(혜택) 정보」에서 매일 새 지원제도와 바뀐 내용을 가져와요.
  2. AI 초안 작성 · AI가 공식 데이터만 사용해 읽기 쉬운 초안을 써요. 데이터에 없는 금액·조건은 쓰지 않아요.
  3. 자동 사실 검수 · 다른 AI가 글을 공식 데이터와 한 줄씩 대조해 금액·날짜·자격요건이 다르면 고쳐요.
  4. 운영자 확인 · 운영자가 게시된 글과 도구를 확인하고, 계산기 기준값은 정부 고시를 직접 찾아 반영해요.
  5. 오류 제보 반영 · 각 글의 '오류 제보하기'로 알려주시면 확인 후 고치고, 바뀐 내용은 베네피 소식에 기록해요.

자료 출처, 확인 방법, 오류 수정 원칙은 운영·편집 원칙에서 자세히 볼 수 있습니다.

지원 조건·금액·기한은 변경될 수 있으므로 신청 전 반드시 담당 기관의 공식 안내를 확인해 주세요.
