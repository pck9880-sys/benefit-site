🎴 카드뉴스 메이커

Claude에게 원고 받는 프롬프트 (복사해서 사용) 
아래 고객 요청으로 인스타그램 카드뉴스 원고를 만들어줘.
- 6~8장 구성: 첫 장 cover, 마지막 장 cta, 중간은 point / list / steps / stat / compare / quote 를 내용에 맞게 섞어서
- 한 장에 글자는 적게 (제목 20자 이내, 본문 80자 이내, list 항목 4개 이하, 항목당 25자 이내)
- 강조할 단어는 <b>단어</b> 로 감싸기
- 사실이 불확실한 수치는 지어내지 말 것
- 아래 JSON 형식으로만 답하고 다른 말은 쓰지 마

{"slides":[
 {"type":"cover","kicker":"짧은 태그","title":"표지 제목","subtitle":"부제"},
 {"type":"point","no":"01","title":"소제목","body":"설명"},
 {"type":"list","title":"소제목","items":["항목1","항목2","항목3"]},
 {"type":"quote","text":"인용/핵심 문장","by":"출처"},
 {"type":"stat","kicker":"태그","value":"73%","label":"숫자 설명","body":"부연 설명 (출처가 있는 수치만)"},
 {"type":"compare","title":"비교 제목","left":{"label":"BEFORE","items":["이전1","이전2"]},"right":{"label":"AFTER","items":["이후1","이후2"]}},
 {"type":"steps","title":"순서 제목","items":["1단계","2단계","3단계"]},
 {"type":"cta","title":"마무리 문구","body":"설명","button":"버튼 문구"}
]}
- cover/point/list/quote/cta 에는 "emoji":"🎁" 를 넣어 큰 아이콘을 붙일 수 있음
- 볼드 테마용으로 cover 에 "sticker":"오픈\n특가" 처럼 원형 스티커 문구 가능
